개인정보처리방침

드기 도감은 개인 수집 기록 서비스를 제공하는 데 필요한 최소한의 정보만 처리하며, 처리 현황과 이용자의 권리 및 요청 방법을 아래와 같이 공개합니다.

시행일 2026년 8월 6일
처리 목적 처리 항목 보유기간 외부 서비스 이용자 권리 만 14세 미만 문의·삭제 요청

1. 개인정보의 처리 목적

드기 도감 운영자(이하 “운영자”)는 다음 목적으로 개인정보를 처리합니다.

  • Google 로그인 이용자 확인 및 로그인 상태 유지
  • 계정별 도감 수집 상태의 저장·불러오기·동기화
  • 건의 및 요구사항 접수, 처리 상태 관리와 답변
  • 중복을 줄인 일별·누적 방문자 및 로그인 이용자 수 집계
  • 서비스 장애 대응, 부정 이용 방지와 보안 유지
비밀번호, 결제정보, 주민등록번호, 위치정보, 연락처는 운영자가 직접 수집하지 않습니다. 현재 광고성 정보 전송이나 맞춤형 광고도 하지 않습니다.

2. 처리하는 개인정보 항목과 수집 방법

구분 처리 항목 수집 방법·이용 목적
Google 로그인 Firebase UID, Google 이메일 주소, 표시 이름, 인증·접속 메타데이터 이용자가 Google 로그인 버튼을 선택할 때 Google/Firebase를 통해 계정 확인과 로그인 유지
도감 기록 도감별 보유·미보유 상태, 직접 입력한 카드 정보, 생성·수정 시각 로그인 이용자가 카드 상태를 변경하거나 시트 동기화를 실행할 때 계정별 기록 저장
건의사항 유형, 제목, 내용, UID, 이메일 주소, 표시 이름, 작성·처리 시각 로그인 이용자가 건의 및 요구사항을 제출할 때 접수와 처리
방문 집계 무작위 방문자 식별값, 접속 날짜, 최초 집계 시각, 로그인 UID의 등록 여부 페이지 접속 시 같은 기기의 하루 중복 집계를 줄이고 이용 현황을 표시
브라우저 저장정보 로그인 유지정보, 로컬 도감 기록, 방문자 식별값, 만 14세 이상 확인값, 관리자용 시트 연결 토큰 브라우저 저장소를 이용한 기능 유지. 시트 연결 토큰은 운영자 계정에서만 사용

무작위 방문자 식별값은 이름이나 이메일과 결합하지 않으며, 운영자는 방문 집계를 위해 이용자의 IP 주소나 브라우저 정보를 Firestore에 별도로 저장하지 않습니다. 다만 호스팅·인증·이미지 제공업체는 서비스 제공과 보안을 위해 IP 주소, 사용자 에이전트 등의 접속정보를 자체 정책에 따라 처리할 수 있습니다.

4. 제3자 제공, 처리위탁 및 국외 처리 가능성

운영자는 개인정보를 판매하지 않으며, 이용자의 개인정보를 독립적인 마케팅 목적으로 제3자에게 제공하지 않습니다. 다만 서비스 제공을 위해 아래 외부 인프라를 이용합니다.

업체·서비스 이용 목적 처리될 수 있는 정보 처리 위치·기간
Google LLC
Google Sign-In, Firebase Authentication, Cloud Firestore		 로그인, 계정 확인, 도감·건의·방문 집계 저장 UID, 이메일, 표시 이름, 도감 기록, 건의 내용, 방문자 식별값, IP·사용자 에이전트 등 인증 메타데이터 Google이 운영하는 국내외 인프라에서 서비스 제공 기간 및 Google의 보관정책에 따라 처리
GitHub, Inc.
GitHub Pages		 웹사이트 정적 파일 호스팅과 전송 IP 주소, 요청 시각, 브라우저·기기 정보 등 접속 로그 국외를 포함한 GitHub 인프라에서 GitHub 정책에 따라 처리

위 서비스 이용 시 정보가 국외에서 처리될 수 있으며, 이용 시점에 네트워크를 통해 전송됩니다. 국외 처리를 원하지 않는 이용자는 Google 로그인과 건의 기능을 사용하지 않고 공개 도감만 열람할 수 있습니다. 다만 공개 페이지 접속에 필요한 GitHub Pages의 기본 통신은 제외할 수 없습니다.

외부 이미지·글꼴 제공 서버

카드 이미지와 글꼴은 포켓몬코리아 이미지 서버, Collectory CDN, Google Fonts 등 외부 서버에서 불러올 수 있습니다. 이 과정에서 해당 제공자에게 IP 주소, 접속 시각, 리퍼러 등의 정보가 자동 전달될 수 있으며, 각 제공자의 개인정보처리방침이 적용됩니다.

자세한 내용은 Firebase 개인정보·보안 안내, Google 개인정보처리방침, GitHub 개인정보처리방침에서 확인할 수 있습니다.

5. 개인정보의 파기 절차와 방법

  • 보유기간이 끝나거나 처리 목적이 달성된 정보는 확인 후 지체 없이 삭제합니다.
  • Firestore의 전자 기록은 해당 문서 또는 계정 데이터를 삭제하고, 브라우저 저장정보는 브라우저 저장소에서 삭제합니다.
  • 백업 시스템에 남은 정보는 서비스 제공업체의 백업 순환·삭제 정책에 따라 삭제됩니다.

6. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대한 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 아래 이메일로 로그인에 사용한 Google 이메일 주소와 요청 내용을 보내면 본인 확인 후 처리합니다. 비밀번호나 Google 인증코드는 보내지 마세요.

브라우저에 저장된 방문자 식별값과 로컬 기록은 브라우저의 사이트 데이터 또는 저장공간을 삭제하여 직접 제거할 수 있습니다. Google 로그아웃만으로 서버의 도감 기록이 자동 삭제되지는 않습니다.

7. 만 14세 미만 이용자

드기 도감의 공개 페이지는 로그인 없이 열람할 수 있지만, Google 로그인과 건의 기능은 만 14세 이상만 이용할 수 있습니다. 운영자는 만 14세 미만 이용자의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만의 정보가 수집된 사실을 알게 되면 본인 또는 법정대리인의 요청을 확인하여 지체 없이 삭제합니다.

8. 개인정보의 안전성 확보 조치

  • Firebase Authentication을 통한 계정 인증과 로그인 사용자별 Firestore 접근규칙 적용
  • 공유 계정의 읽기 전용 권한과 운영자 권한 분리
  • HTTPS 통신, 최소 권한 원칙 및 불필요한 공개 차단
  • 비밀번호를 사이트가 직접 수집·저장하지 않는 Google 인증 방식 사용

인터넷 전송과 전자적 저장의 특성상 절대적인 보안을 보장할 수는 없으나, 사고 발생 시 관련 법령에 따라 필요한 조치를 합니다.

9. 외부 링크와 자동화된 결정

사이트에는 포켓몬 카드 공식 사이트, Google, 외부 이미지 제공 서버 등으로 이동하는 링크가 포함될 수 있습니다. 외부 사이트에서 이루어지는 개인정보 처리는 해당 사이트의 정책을 확인해 주세요.
